# 一分钟演示脚本（初赛视频）

> 目标：60 秒内让评委看懂「这是什么、解决谁的什么问题、凭什么可信」。
> 评分对应：赛道契合 25 / 功能完成度 40 / 应用价值与可验证性 25 / 视频表达 10。
> 本脚本只写画面与口播，不写实现细节；技术细节留给答辩与文档。
> 版本：v4（2026-11-21，加入产品台、用户画像、证据模式、浅色主题与评测终端）

---

## 录制前准备

| 项 | 要求 |
|---|---|
| 数据 | 已执行 `build_real`，首页数据带显示 6 行业 / 18 家 / 54 份 / 1,015 条 |
| 报告 | 已有一份青岛啤酒 v3 报告（含 AI 阅读提示）；版本页有 v1/v2/v3 历史，可现场生成补证预览 |

| 字幕 | 关键数字用后期字幕强调，不要靠口播听清 |

## 分镜（60 秒）

### 0:00–0:05｜命题与痛点（5s）

- **画面**：首页首屏，标题「把结论，钉回年报那一页。」
- **操作**：鼠标从标题缓慢移到右侧报告卡。
- **口播**：
  > 「行业研究不缺结论，缺的是复核——这个数字，到底来自年报的哪一页。」

### 0:05–0:15｜产品是什么（10s）

- **画面**：停在「一张底稿，三个工作面」的产品台。
- **操作**：依次点「报告」「证据地图」标签，让三块工作面各停留约 2 秒；不展开细节。
- **口播**：
  > 「不是聊天框，是一张研究底稿：研究台、报告、证据地图，
  > 三个工作面，给券商、银行、企业战略共用。」

### 0:15–0:25｜四层证据链与证据地图（10s）

- **画面**：停在「报告」页的「四层证据链」条。
- **操作**：点「演示一条」；抽屉从右滑出，四层链依次点亮：口径 → 算式 → 单元格 → 原件，最后停在原页红框。
- **口播**：
  > 「点开毛利率：口径、算式、原表单元格、带校验码的原件，四层依次点亮；
  > 证据地图再把结论连回原件。」

### 0:25–0:35｜报告、证据模式与追问（10s）

- **画面**：进入「报告」页，点顶部「证据模式」。
- **操作**：让无引用段落变灰的对比停 2 秒；悬停一条引用，弹出原表单元格；再点一个推荐追问。
- **口播**：
  > 「打开证据模式：没有依据的段落自动变灰；悬停引用，直接看原表单元格；
  > 追问只答这个版本。」

### 0:35–0:47｜补证与增量（12s）

- **画面**：切到「版本与补证」，选择演练更正公告，点「生成增量预览」。
- **操作**：指向「2 个事实 / 3 个指标 / 6 节改写」，再指「industry、chain 版本不变」。
- **口播**：
  > 「新材料只改该改的：先算影响范围，六个章节改写，
  > 行业和产业链沿用同一版本。」

### 0:47–0:57｜评测与边界（10s）

- **画面**：切到「评测」页，停在失败样本故事卡。
- **操作**：指向 −54,748,707.69 / 3,096,948,816.62 / 不一致，再点「打开四层证据」；最后扫过回归赛道卡片。
- **口播**：
  > 「评测不给自己出题：年报对第三方 84.1% 一致，61 条不一致全公开；
  > 点开一条——母公司表被标成合并口径，31.5 亿差额回到原页。
  > 三条回归在独立环境跑。」

### 0:57–1:00｜收尾（3s）

- **画面**：回到首页结尾「从一个数字开始」。
- **字幕**：经营证据链 · 每个数字都能回到那一页。

## 口播总字数与节奏

全文约 237 字，按每秒 4.1 字计，约 58 秒。若超时，优先压缩 0:15–0:25 的第二句，
保留「四层证据链」「失败故事」与「多智能体」三段——它们分别对应产品体验、可验证性与赛道契合。

## 备用方案

| 故障 | 处理 |
|---|---|
| 服务未启动 | 提前录制备份视频；或现场 `.\start.ps1`，10 秒内可起 |
| 追问无响应 | 改为点推荐问题（已按当前报告动态生成），不要现场输入长句 |
| 增量预览过慢 | 提前生成一次草稿，视频里直接展示影响面与章节版本 |
| PDF 页图慢 | 证据抽屉会自动降级为「定位 + 摘要」，仍可展示四层结构 |
| 投影偏色 | 提高亮度；红色点缀在暗色投影下仍可见，青柠色是主色 |

---

## 不要做的事

- 不要念技术名词（DAG、FactKey、BFS）——评委关心「能不能用、可不可信」。
- 不要展示 100% 的真实精度；展示 84.1% 与失败样本，比完美数字更有说服力。
- 不要把「AI」当卖点；卖点是「AI 的输出可以被复核」。
- 不要把演练更正公告说成真实公告；画面里的「非真实披露」标识必须保留。
